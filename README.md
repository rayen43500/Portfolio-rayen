# Rayen Houaidi · Developer Portfolio

Portfolio moderne et professionnel construit avec React + Vite.

## Positionnement

- Software Engineer orienté full-stack, mobile et backend
- Focus business: scalabilité, sécurité, performance et valeur produit
- Domaines clés: web apps, APIs, cloud-ready systems

## Sections incluses

1. Hero / Value Proposition
2. About Me orienté client
3. Technical Skills par domaine
4. Featured Projects en format case study
5. Services Offered
6. Experience & Education concis
7. Contact & Call-To-Action

## Stack

- React
- Vite
- CSS moderne avec thème dark/light

## Exécution locale

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
```
